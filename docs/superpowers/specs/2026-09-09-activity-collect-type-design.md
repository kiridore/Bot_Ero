# 活动新类型「征集」（collect）设计

日期：2026-09-09 · 状态：已确认（对话内逐项裁定）

## 目标

新增第三种活动类型 `collect`（征集）：成员报名后各自在截止时间前提交**一次**作品（可更新），无接龙流转、无匹配配对——即「简单征集」。

## 决策表

| # | 决策 |
|---|------|
| D1 | 复用成员制骨架：`/活动 加入` 报名 → 创建人 `/活动 开始`（报名截止到点自动开始同样适用） |
| D2 | 语义 = match 去掉配对环：任意时间提交一次、截止时间必填、心跳到点 pending→missed→归档 |
| D3 | 提交更新：截止前允许更新（文字+图片），web 增量图片语义（追加/单删）直接继承 |
| D4 | 退出：running 中退出仅标记 `left`，无链环修复；报名中退出照旧（转移创建人/人数归零取消） |
| D5 | 最低人数 1（同接龙）；`hours_per_user` 不适用（仅 relay 存） |

## 改动点

**bot（plugins/activity）**
- `/活动 创建 征集 <标题> [描述] [报名截止 …] 截止 …`：参数解析复用 match 分支；截止必填（缺省报错文案同匹配）
- `_start_activity`：collect 分支——人数 ≥1、不建链环（成员 seq 沿报名序）、群公告「征集活动开始」、无私聊（无下家/无首棒）
- `_handle_leave_running`：collect 分支仅标记+公告
- 状态/播报/归档文案三类型化：接龙/匹配下家/征集；归档作品标题 relay=「接力」其余=「作品」
- `/提交` 与心跳 deadline 收尾本就类型无关，零改动

**web（webapp/activities）**
- `ActivityCreateIn.type` pattern 加 `collect`；创建校验 `match|collect` 截止必填；开始人数校验 collect ≥1
- 前端：创建页类型 radio「征集」（截止必填、限时行隐藏）；列表/详情/管理/分享长图 `TYPE_LABEL` 加 `collect: 征集`；详情页无轮次/无下家（match 渲染路径天然兼容）

## 测试清单

- bot：征集创建（缺截止报错/成功播报）、加入、开始（1 人可开）、提交、退出标记、心跳到点收尾归档
- API：创建 collect 无截止 400、有截止 200、start/submit/finish 全流程
- 回归：全量 pytest（含既有 relay/match 用例不回归）

## 非目标

- 免报名直接提交（重造提交权模型，收益低）
- 征集专属统计页/作品投票（归档作品展示已覆盖）
