# 用户协议v1

感谢你使用本服务。注册前请阅读并同意以下条款。

## 1. 服务性质

- 本服务由个人开发者**业余时间维护**，非商业产品。
- 问题处理与响应以**天**为单位，不承诺即时支持；不设服务等级承诺。
- 功能可能随版本更新调整或下线，重大变更会尽量提前公告。

## 2. 我们收集哪些数据

为提供功能，服务会记录：

- 你的 QQ 号（作为账号标识）
- 你主动提交的打卡记录与图片、活动与游戏参与记录
- 积分、称号等玩法数据
- 本服务不记录、不存储群聊消息内容（仅处理发往机器人的指令）

不收集聊天内容用于任何分析；不会向第三方出售或提供你的数据。

## 3. 数据的使用与保留

- 数据仅用于本服务的功能运行、统计展示与滥用防护。
- 你可以申请导出或删除自己的数据；退出（删除好友/退群）后，历史数据可申请删除，且会在合理期限内清理或匿名化，法律允许保留的备份除外。

## 4. 行为规范

禁止以下行为，违反者可能被限制功能或列入黑名单：

- 刷取积分、滥用概率玩法、利用漏洞
- 使用脚本批量发送指令、干扰其他用户
- 发布违法内容或利用本服务传播违规信息
- 政治相关。我们不讨论、评价国家政策及国家领导人。若你在其他平台有此类负面发言，这里也不欢迎你。
- 血腥、暴力、赌博、毒品、涉黑相关。若你在其他平台有此类负面发言，这里也不欢迎你。
- 色情相关，包括擦边内容。
- 恶意引战内容。包括易对立话题。
- 诋毁、侮辱他人的内容。包括挂人带节奏。
- 谣言、欺诈、黑产类内容。
- 提交AIGC内容

## 5. 免责声明

- 服务按"现状"提供，不对数据丢失、服务中断造成的损失承担责任（会尽力备份）。
- 因不可抗力、第三方平台（QQ 相关接口）变更导致的服务变化，不视为违约。

## 6. 协议变更

协议如有变更，会在菜单或公告中提示；重大变更会要求重新确认。
