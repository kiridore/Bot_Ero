# 子应用界面风格统一（报纸风）实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把 6 个子应用（gallery/profile/trpg/guestbook/alarms/activities 约 10 个页面）从旧暗色主题（#0f1115 深底/蓝强调）统一为与导航主页一致的报纸风设计语言（米黄纸张/衬线/苔绿/柔和圆角阴影）。

**Architecture:** 子应用全部样式经由 `core/web/static/gallery.css` 的 `:root` token（唯一来源）+ var() 引用传播——把 token 换为报纸风数值、重写基础组件（toolbar/dialog/按钮/输入框）、清理 profile.css 与各域专属 css 的硬编码色即可全局翻转。布局保留各页功能结构（sticky 工具栏变报纸风横条，不复制导航页大报头），语录/公告栏等导航页专属元素不扩散。`homepage/` 因 Caddy 独立托管无法引用 /shared/，保留自带 token（数值与共享一致，注释标注同步义务）。

**Tech Stack:** 纯 CSS（CSS 变量/选择器/伪元素）+ 少量 HTML 类名微调，无 JS 改动。

## Global Constraints

- 设计基准 = `homepage/style.css` 的 `:root` token（报纸风，逐值一致）：`--paper:#f5efe0` `--paper-card:#fbf7ec` `--ink:#2c2a24` `--ink-soft:#6b6350` `--line:#8a7f63` `--rule:#b8ad8e` `--accent:#5f7a68` `--accent-soft:#e4e9dd` `--accent-ink:#3f5347` `--gold:#b49a5e` `--green:#4a7c4f` `--red:#b0533f` `--gray:#a8a294` `--shadow-sm/md/lg` `--radius-sm:6px` `--radius-md:12px` `--motion-fast:150ms` `--motion-base:250ms` `--ease:cubic-bezier(0.22,1,0.36,1)`；字体 `Georgia, "Songti SC", "Noto Serif SC", "SimSun", serif`；body 背景 `var(--paper)` + 点阵噪点纹理（radial-gradient 1px rgba(44,42,36,0.035) / 22px 22px）
- **布局结构不改**：各页面现有 HTML 结构与类名保留（.toolbar/.profile-toolbar/.profile-main/.filters/.login-dialog/.lightbox 等），只改 CSS 与必要的类名微调
- 不改 JS（auth.js/各域 js 零改动）；不改任何后端
- 导航页专属元素（语录栏/公告栏/印章角标/服务卡片网格）**不**进入子应用
- lightbox 遮罩（暗色看图背景）功能性保留，允许深色
- 硬编码色清理范围：gallery.css、profile.css、guestbook.css、alarms.css、trpg.css 中所有非 token 色值（清单见各任务）
- homepage/style.css 的 :root 数值**不得改动**（它是基准），只允许在注释中标注"与 core/web/static/gallery.css :root 保持同步"
- 提交消息：中文 Conventional Commits
- 每任务验证含：token 数值与 homepage 一致（diff 命令）、子应用 curl 冒烟、`import plugins` OK

import re
def tokens(path):
