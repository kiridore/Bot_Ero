# 议事厅实施计划（2026-08-10）

> 权威设计：`docs/archive/superpowers/specs/2026-08-10-forum-design.md`；协议：`specs/timeline-protocol.md`（新增 `forum` source）。

**Goal:** 长文/公告/投票/评论的社区议事空间，所有用户消息自动汇入时间线；bot 心跳发群消息 + 关闭过期投票。

**Architecture:** webapp 第 9 个模块 `webapp/forum/`（10 API + 4 页面）+ `plugins/forum_notify/` TimedHeartbeatPlugin 变体（手动分钟去重）。事件源 `forum`，dedup_key 三种：`forum_post:<id>` / `forum_comment:<id>` / `forum_poll_close:<id>`。

**Tech Stack:** FastAPI + SQLite (WAL) + Tiptap 2 (ESM CDN) + 原生 JS + 现有 newspaper theme tokens。

## Global Constraints

- Event Server 不解析 `data`，新增 `forum` source（`specs/timeline-protocol.md` §已注册 source 表）
- 发送 best-effort：失败仅记日志，不阻塞主流程
- 投票一人一票由 `UNIQUE(poll_id, user_id)` 强制；多选字段已留 `poll_allow_multi` 备用（v1 固定 0）
- 公告每日 1 次：`SELECT COUNT(*) ... WHERE author=? AND type='announce' AND substr(created_at,1,10)=today`
- 长文 Tiptap JSON 单源存储，渲染在详情页客户端 `generateHTML`
- 提交消息：中文 Conventional Commits；文档与代码同 commit
