# BotEro 公开化与市场化改造计划（供人工审阅）

> **文档性质**：产品 / 社区运营策略计划，供人工审阅与拍板，**非技术实施方案**——技术改造点仅在影响产品形态处点到为止。
> **起草日期**：2026-08-23 · 基于当前 1.21.x 架构（bot 47 插件 + webapp 11 模块，用户规模约 15 人）
> **修订**：2026-08-23 v2——第 6 章按所有者的常驻生存设计重写（双模式 + 自动化硬约束 + 命名与规则公告）

## 0. 结论摘要

BotEro 真正值钱的是两样东西：**「打卡 → 积分经济 → 称号收集」这套被 15 人社区长期真实使用打磨过的养成循环**，以及围绕它自然长出来的**社区内容沉淀能力**（图库 / 时间线 / 议事厅 / 活动归档 / 周报）。

推向市场的本质不是堆功能，而是完成三个替换：

1. 把**熟人小圈子的信任假设**换成**开放社区的规则与审核**（举报、处置、机审、频控）；
2. 把**QQ 单群入口**换成**开放注册的账号体系**（QQ 降级为可选绑定渠道）；
3. 把 **FF14 / 内部梗的私域皮肤**换成**可配置的通用主题**（称号池清洗、数值配置化、文案中性化）。

同时以「**绝地画室**」（大逃杀绘画打卡：常驻生存 + 季度锦标赛双模式，见第 6 章）作为第一个面向市场的招牌玩法，**先在现有社区以纯手动方式内测**（管理员表格结算 + 手写战报，不写代码），验证玩法节奏后再投入开发——玩法风险先于工程投入被验证。

## 1. 现状盘点

**产品本质**：绘画打卡工具 + 游戏化养成（积分 / 抽卡 / 称号）+ 社区内容站。QQ 群是唯一入口，Web 站全站登录门控（密钥需私聊向 bot 索取），经济与内容全站共享一个池。

**可直接迁移的核心资产**（市场化后立刻能用）：

- 打卡主流程：图片打卡 / 撤回 / 补卡 / 周常任务 / 热力图档案 / 排行榜——完整、边界情况处理细致（撤回回滚、补卡排除统计等）
- 经济循环：打卡 → 积分 → 抽卡 → 称号收集 → 商店轮换，数值经过长期调平（含期望收益测算与通胀结论）
- 活动系统：接龙 / 匹配两种玩法，含报名、限时、私聊提交、自动归档全流程——**大逃杀的直接地基**
- 社区内容栈：时间线（事件协议 + 未读体系）、议事厅（长文 / 公告 / 投票 / 嵌套评论）、图库、留言簿、工具箱
- 内容运营资产：242 个称号、菜单文案体系、自动周报

**市场化前的隐性负债**：

- 身份 = QQ 号：账号不可自注册、不可找回，昵称 / 头像依赖 OneBot 反查
- 单群假设贯穿全站：默认群号、周报、消息记录、经济池全绑在"一个群 = 一个社区"上
- **零内容审核**：打卡图、论坛图文、留言、外链、活动作品全部先发后见，无举报、无处置、无日志
- 全量群消息永久记录（message_logger）——公开产品不可接受的隐私形态
- 大量私域内容：FF14 玩法复刻（仙人彩 / FF 新闻）、Werwolf 与 FF14 系称号池、内部梗文案、绑定个人的直播间模块

## 2. 先拍板：三个方向性决策

以下三个决策决定后文所有改动的形态，建议最先审阅。

### D1 产品形态

| 选项 | 说明 | 优点 | 代价 |
|---|---|---|---|
| A. 托管平台（SaaS） | 用户注册即用，官方运营大社区（或可自建圈子） | 网络效应、数据可控、商业化空间 | 审核合规成本全部自担；第 3 章改造需全项完成才能上线 |
| B. 自部署套件 | 像 NoneBot 插件那样分发给群主自建 | 合规责任分散、借群主触达绘画群、贴合现状（本就是 bot 形态） | 无网络效应、版本碎片化、难商业化 |
| **C. 先 B 后 A（推荐）** | 以"绘画打卡社区套件"分发验证需求；littlero 官方站改造为示范旗舰社区，承接想跨群社交的用户 | 低成本试水；官方社区即样板间 | 双线维护的节奏问题 |

推荐 C 的理由：现有架构（bot 插件 + 单进程 webapp + 单文件 SQLite）天然贴近自部署形态；托管平台则需先完成第 3 章几乎全部改造，周期长、风险集中。

### D2 平台重心

QQ-first（现状）还是 Web-first？绘画打卡的目标用户大量在 QQ，但**提交作品、浏览画廊的高频场景在手机端网页**。建议：双端并行、分工明确——QQ bot 保留为"游戏化指令 + 提醒触达"通道，Web 承担注册、提交、浏览、社区全部主流程；市场化后新功能 Web 优先。

### D3 社区结构

- **单一大广场**：所有用户共享一条时间线 / 论坛 / 排行榜（现状模型的放大）
- **多圈子（班级 / 画会）**：用户可建圈，圈内独立打卡主题 / 排行 / 时间线，广场做跨圈内容分发

推荐：**公开版从单一大广场起步，圈子作为 Phase 2 功能**。15 人 → 数百人的阶段，一个大社区的活跃密度本身就是留存手段；过早多圈会把稀薄的活跃度切成一片死圈。圈子所需的隔离与权限复杂度，应等增长验证后再投入。

## 3. 市场化必须完成的改造（按域，功能 / 模块层）

托管版以下全项必做；自部署版打 `*` 的为强烈建议项。

### 3.1 账号与准入

- 开放注册（邮箱 / 手机验证码；QQ 授权登录作为**可选**快捷方式）——QQ 号从"身份本体"降级为"绑定渠道之一"
- 现有密钥登录（HMAC）退役为兼容通道；增加密码找回
- 昵称 / 头像用户自设，OneBot 反查降级为"绑定 QQ 后自动填充一次"
- 新手引导：注册 → 选打卡目标 → 引导完成首次打卡（衔接新手 7 日挑战，见第 5 章）
- 用户协议 + 隐私政策 + 社区内容规范三件套，注册即同意 `*`

### 3.2 内容审核与合规（"用户提交"视角的核心改造）

现状所有 UGC 提交点（打卡图、论坛图文、留言、工具箱外链、活动作品）都是先发后见、无举报、无处置。公开版每个提交点都需要：

- **统一举报组件**：打卡图 / 帖子 / 评论 / 留言 / 链接 / 活动作品可一键举报
- **管理处置流**：举报队列 → 下架 / 删除 / 警告 / 封禁，处置留痕可追溯
- **机审前置**：图片接入内容安全审核（自部署版做成可选开关）；文本敏感词过滤
- **外链治理**：工具箱提交增加域名黑白名单 + 举报下架（现状仅提交者本人可删；roadmap 2.0 已列"管理侧审核流"，此项为前置）
- **频控与配额**：新用户发图 / 发帖 / 评论设每日上限，防灌水刷分
- **合规红线清单**（国内运营）：ICP 备案与 APP 备案、手机号实名、未成年人保护（内容分级 + 时段）、**取消一切"下注竞彩"式玩法**（见 4.1 仙人彩）、**全量消息记录必须移除**
- **版权与可见性**：用户保留作品版权、平台仅获展示许可；打卡图默认登录可见（现状已是），"公开橱窗"由作者逐作品自愿选择 `*`

### 3.3 社区权限与运营后台

- 权限分级：超管 → 版主（内容处置 / 活动主持，可按模块授权）→ 普通用户；替代现状"硬编码超管列表 + 群管理员身份"
- **运营后台**（Web 新模块）：内容管理（帖 / 图 / 链接 / 活动的下架与恢复）、用户管理（封禁 / 警告 / 积分调整）、举报队列、数据看板（DAU / 留存 / 打卡率 / 活动参与度）
- 公告体系：复用议事厅公告类型 + 全站横幅，替代"bot 群播"

### 3.4 打卡玩法泛化

- **打卡主题可配置**：周主题 / 月挑战由运营或版主设置，展示于打卡页与时间线（现状无主题概念）
- **社区级提醒**：周一打卡提醒、活动截止前提醒、大逃杀轮次提醒（现状仅用户自建闹钟）
- **数值配置化**：抽卡概率、商店价格、补卡费用、周常任务全部转为配置（现硬编码于代码），供各社区 / 各部署自行调平 `*`
- 打卡类型扩展预留：图片为主，预留文字 / 链接打卡（扩大到非绘画场景的可能，首版可不做）

### 3.5 经济公平与反作弊

- 反小号：注册门槛 + 排行榜异常波动检测（积分经济对多账号刷分天然脆弱）
- 防旧图重提：不设自动质量/查重判定（自动化边界见 6.6）——相似图检测仅作为管理员人工复核的辅助工具，处罚判定一律由人做出
- **赛季制**：排行榜与部分称号按赛季重置，防头部固化劝退新人（见第 5 章）
- **AI 生成作品政策**（必须明确公示）：允许 / 禁止 / 分区三选一；竞赛类玩法默认"禁止纯 AI 直交、允许辅助并标注"

### 3.6 触达与召回

- 站外通知：邮件为底线渠道；微信公众号 / 群 webhook 为国内增强（QQ 群消息仅覆盖 QQ 侧绑定用户）
- 事件订阅：用户可选订阅"关注的创作者更新 / 我参加的活动 / 大逃杀赛况"
- 流失召回：连续 N 天未打卡的温和提醒（用户可关闭）

### 3.7 移动端体验 `*`

- 全站移动端适配（现状报纸风为桌面布局，窄屏仅侧栏降级）；**打卡上传的移动端体验最优先**（多图、压缩、进度反馈）
- PWA：加桌图标 + 推送预备

## 6. 重点设计：绝地画室（大逃杀绘画打卡 v2）

> v2 修订说明：本章融合所有者的**常驻生存设计**（群即游戏、每周一画、不交则亡）与初版锦标赛设计，重组为双模式；并确立自动化硬约束——**LLM 仅用于自然语言（指令意图解析 / 战报文案生成），禁止用于画作分析；不设任何与画作质量相关的自动规则，质量违规仅由管理员人工撤销**。

### 6.1 双模式结构

| | 模式 A：常驻生存（日常，本设计的核心） | 模式 B：季度锦标赛（节日事件） |
|---|---|---|
| 形态 | 群 / 圈子本身即游戏，长期常驻 | 离散赛事：报名 → 多轮 → 夺冠 → 归档 |
| 生存压力 | 每结算周 1 次打卡，未交进入死亡流程 | 每轮主题限时提交，缺席 / 投票出局 |
| 对标 | 「不画画就退群」死亡小组 | Art Fight / 无限流淘汰赛 |
| 定位 | 日常养成与留存主引擎 | 季度社区节日与拉新爆点 |

两模式共享同一套地基：打卡提交通道（= 普通 `/打卡`）、积分 / 商店 / 称号管线、时间线事件、归档、周报。常驻模式的段位同时作为锦标赛的报名门槛与奖励倍率。

### 6.2 模式 A：常驻生存（原设计优化版）

**生命周期状态机**

```
入群 → 新生期(7×24h, 免打卡) → 存活（加打 / 连击 / 段位成长）
                                   │ 周一 08:00 结算，未提交
                                   ▼
                          濒危期（24h 宽限，私聊提醒）
                  人工动作：补交(扣2分) 或 /续命 主动用道具
                                   │ 期满仍无动作 → 自动按序消耗：护盾 → 复活券
                                   ▼
                                 阵亡
                  温和档（默认）：转围观席（可互动 + 复活任务），连续 2 周未复活才移出
                  硬核档（可选）：直接移出群聊（冷却 7 天可申请回归）
                                   │ 复活任务完成 / 回归申请通过
                                   ▼
                          回到存活（连击清零；总存活周数 / 段位 / 归档作品保留）
```

**结算周期**：沿用全站周边界（周一 08:00 → 次周一 08:00），与现有打卡 / 补卡 / 周常任务同一把尺子；结算时刻自动发布当周战报。

**原设计四条规则的修订对照（供审阅）**

| 原规则 | 问题 | 修订 |
|---|---|---|
| 1. 群主=机器人，全员每周提交 | 成立；且机器人任群主恰好一次性解决踢人 / 头衔 / 邀请权限 | 保留；补豁免名单公开制（管理员 / 裁判 / 围观席不参与生存） |
| 2. 未提交即移出群聊 | ①**与规则 4 冲突**：复活机会本应在"死后"使用，但人已被移出群、失去群内交互通道，复活无从执行；②无回归通道——公开版等于主动清退用户；③**死亡螺旋**：固定人口 + 持续清退，群体必然收缩，人越少监督越弱、死得越多 | 死亡三级缓冲（濒危宽限 24h → 护盾 / 复活券自动抵扣 → 才判阵亡）；阵亡分档（围观席默认、移出为硬核可选档）；复活任务 + 回归申请通道；全员存活群体奖励对冲死亡螺旋 |
| 3. 首周免打卡 | 「首周」口径模糊：周六入群者的首周是 2 天还是到下周一？ | 新生期 = 入群时刻起 7×24 小时，与自然周解耦 |
| 4. 存活一个月得复活机会 | ①「一个月」口径不明（自然月 28-31 天不等）；②无上限 / 过期 / 消耗规则；③获得与使用的时机未定义 | 每**连续存活 4 个结算周** +1 张，持有上限 2、不过期；濒危期满按 护盾 → 复活券 顺序**自动消耗并私聊通知**；复活券不可购买（资历专属），护盾可购买（金钱兜底，持有上限 1）——两条续命线分开，防「有钱不死」 |

**节奏选择（对应「提高打卡次数或改变结算周期」）**

| 方案 | 判定 |
|---|---|
| **每周 1 次生存底线 + 可选加打奖励（推荐）** | 绘画产出节奏的现实解；加打喂给现有周常任务（3/7 次打卡线），每多 1 幅 +1 积分（上限 3/周）——增频不增压 |
| 生存底线提高到每周 2-3 次 | 仅用于硬核分区；对休闲画手劝退率过高 |
| 双周 / 月结 | 不推荐：稀释周期性死亡威胁，大逃杀的核心张力消失 |
| 每日结 | 绘画不现实 |

**趣味机制（对应「其他有趣的内容」）**

- **段位头衔自动佩戴**：存活周数 → 新生 / 见习生(1-3) / 学徒(4-11) / 画师(12-23) / 大触(24-47) / 画室之魂(48+)，结算时自动更新群头衔（复用现有 `/群头衔` 能力，≤10 字）
- **社交互赠**：存活者可把护盾赠给濒危画友（每结算周期限 1 次）——危机时刻的互助是最强的社交绑定
- **大赦日**：春节 / 周年等节点全员复活一次、围观席清空
- **群里程碑**：全群连续全员存活 N 周 → 全员积分 + 里程碑纪念称号（把「别让同伴死掉」变成集体目标，直接对冲死亡螺旋）
- **结算战报**：战报文案由 LLM 生成（纯文本、自然语言处理，不触碰画作）——约束允许范围内最大的趣味放大器
- **补卡与生存的关系**：现有补卡（2-4 积分）仅修补热力图 / 统计记录，**不恢复生存状态**（生存只能靠按时提交或护盾 / 复活券），避免两套续命经济打架

### 6.3 模式 B：季度锦标赛（原赛程设计压缩保留）

- **赛程**：创办（轮数 3-5、每轮 48-72h、淘汰规则、人数 8-20，报名门槛挂常驻段位）→ 报名期（可只围观）→ 每轮：公布主题（用户征集池公开抽取）→ 限时提交（重复覆盖）→ 评定 → 结果与轮次画廊 + 时间线事件 → 决赛（终极主题）→ 整期归档（赛程 / 每轮画廊 / 冠军专题）
- **淘汰机制**：缺席淘汰（基础）/ 匿名投票淘汰（中后期，平票兜底）/ 评审淘汰（有嘉宾资源的正式赛）；推荐**渐进混合制**。投票与评审是人类判断，不属于「AI 分析画作」禁区
- **与模式 A 的关系**：锦标赛是常驻段位玩家的「晋级日历」——季度大赛（大奖励 + 限定称号）与月度单日速写快赛（低门槛）交替；淘汰者转评委席、可参加复活赛，全部作品入「阵亡者画廊」荣誉化展示

### 6.4 积分与头衔经济（对应「增加积分或奖励机制，兑换群聊头衔」）

| 流向 | 明细 |
|---|---|
| 获取 | 每周按时存活 +1；连续存活 4 / 12 / 24 周里程碑 +2 / +5 / +10；每周加打每幅 +1（≤3）；全员存活周全群 +1；主题周参与 +1；锦标赛名次递增奖励 |
| 消耗·生存 | 护盾 3 积分（持 1 上限）；濒危期补交 2 积分；锦标赛报名费（可选） |
| 消耗·荣耀 | **自定义群头衔 12 积分 / 28 天**（≤10 字，管理员可驳回）；限定头衔仅活动发放、不可兑换；Web 公开版同步映射到称号体系 |
| 不可购买 | 复活券（仅连续存活获得） |

经济尺度：与全站积分同池（现体系每周任务总收入约 +14，本玩法周获取 ≤ +5，不引发通胀）；头衔是核心荣耀出口——QQ 头衔 10 字上限与 bot 写头衔能力已由现有插件验证。

### 6.5 负反馈削减设计（对应「削弱负反馈」）

1. **三级缓冲垫在死亡之前**（宽限 → 护盾 → 复活券），自动消耗 + 私聊通知，不搞公开处刑
2. **措辞中性游戏化**：濒危 / 阵亡 / 复活 / 围观席；公告与战报不使用「失败 / 出局」点名批评
3. **阵亡 ≠ 离场**：围观席保留全部互动权限；**复活任务** = 为 3 幅本周作品各写一句评论（评论条数是脚本可校验的客观行为，不涉质量判定）——把出局者的注意力转化为社区互动量
4. **回归不清零历史**：连击清零已是代价，总存活周数 / 段位 / 归档作品全保留
5. **大赦日与全员奖励**制造集体幸存叙事，而非个人淘汰叙事

### 6.6 自动化边界与 LLM 约束映射

| 约束 | 落到设计 |
|---|---|
| LLM 仅限自然语言 | ✅ 指令意图解析（自然语言 → 结构化操作）、结算战报 / 公告文案生成、主题库文本去重聚类 |
| 禁止 AI 分析画作 | ✅ 不存在任何自动质量 / 相关性 / 查重判定；§3.5 的相似图检测相应降级为管理员人工复核的辅助工具 |
| 无质量自动规则，管理员撤销 | ✅ 管理员撤销 = 现有撤回打卡 / 回滚机制；**边界规则**：撤销发生在结算之后时，当事人按濒危处理（24h 补交），补交不及才走阵亡流程；撤销必附理由并私聊通知 |
| 操作 = LLM / 指令识别 + 脚本执行 | ✅ 全部玩法操作映射为 `/指令`（CommandPlugin 现实路径）；自然语言前端为可选增强层（注：`core/llm` 现为弃用状态，启用 NLU 需与 AGENTS.md「不新增 LLM 依赖」约束对齐后另行立项） |

提交格式建议（格式规则而非质量规则）：打卡**建议**附一句文字说明（画了什么 / 用时），缺说明不判违规，仅提升社区可聊性；是否强制列为待决。

### 6.7 社区运营设计

- **淘汰者留存**：评委席 / 复活赛 / 阵亡者画廊荣誉化（全部轮次的全部作品含首轮出局者）
- **主题库 UGC**：作品之外，主题本身也是提交入口（征集 → 去重 → 入池 → 公开抽取）
- **观赛体验**：赛况面板（存活名单 / 主题倒计时 / 轮次画廊）；时间线事件覆盖轮开始 / 淘汰 / 晋级 / 夺冠；决赛可配合「一起画自习室」直播创作
- **赛程日历**：常驻每周结算 + 季度锦标赛 + 月度快赛，形成日历感；20 人以上锦标赛分组赛防「陪跑等死」
- **心理安全**：游戏化措辞、新人首赛安慰称号
- **前置依赖**：时间线事件需 roadmap 2.0「事件来源注册表与速率限制」先行（否则结算事件刷屏）；周报数据源站内化后战况自动入周报

**🎨《绝地画室》开业公告**

> 欢迎来到绝地画室——一间不画画就会消失的画室。在这里，画画不是任务，是续命。

**【生存法则】**

1. 每个结算周（周一 08:00 → 次周一 08:00）至少提交 1 幅画作：`/打卡 + 图片`
2. 周一 08:00 结算，未提交者进入 **24 小时濒危期**（私聊提醒）：补交扣 2 积分，或由道具自动续命
3. 濒危期满仍无动作 → **阵亡**：转入围观席（可围观 / 点赞 / 评论，随时可复活回归）；连续两周未复活则移出群聊，回归通道永远敞开（冷却 7 天）
4. 群主（小埃同学）与管理员不参与生存，只负责记账、结算，以及提醒你

**【新生保护】** 入群起 7 天为新生期，免打卡义务——先熟悉规则、随便逛逛，第 8 天开始进入结算。

**【续命道具】**

- 🛡 护盾（3 积分，最多持 1 张）：濒危期满时自动抵挡一次未打卡
- 🕊 复活券（**不可购买**）：每连续存活 4 周获 1 张（最多存 2 张），濒危期满自动使用
- 🤝 互赠：可以把护盾送给濒危的画友（每周限 1 次）——画室虽残酷，板油有真情

**【积分与头衔】**

- 每周按时存活 +1 分；连续存活 4 / 12 / 24 周再 +2 / +5 / +10；每周多画 1 幅 +1（至多 +3）；全员存活周全群 +1
- 段位随存活周数自动佩戴：新生 → 见习生 → 学徒 → 画师 → 大触 → **画室之魂**
- 自定义头衔 12 积分 / 28 天（10 字以内，管理员可驳回）；限定头衔仅活动发放，有钱也买不到

**【阵亡与复活】** 阵亡不是失败——你的作品永远留在画室归档。完成复活任务（给 3 幅本周作品各写一句评论）即可申请回归；连击清零，但你活得够久的证明（总存活周数、段位）全部保留。

**【管理员条例】** 画作质量不参与任何自动判定，画得再抽象也算存活；但与绘画完全无关的提交（白图、表情包、网图直传）管理员有权撤销，撤销后 24 小时内可补交。发现违规请回复该消息并 @管理员。

**【指令速查】** `/打卡` 提交 · `/状态` 查看存活 / 积分 / 道具 · `/兑换 护盾` 购买 · `/续命` 濒危期主动用道具 · `/赠送 护盾 @某人` 互赠 · `/复活` 完成任务后申请回归

节日大赦：春节等大节点全员复活一次，一个都不许少。
