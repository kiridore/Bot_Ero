# 指令使用上限

配置主config.yaml：

```yaml
community:
  command_limit_per_minute: 20
```

修改后重启。缺键或0关闭，旧配置升级不会自动开启；公开候选模板填20。只用实际配置，不由edition选择。cmd_cooldown_seconds是另一个尚未实施的同指令冷却字段，不能替代本配置。

- 同一QQ账号跨群和私聊共用最近60秒的20次额度；超级用户也受限。
- 匹配到允许执行的指令才计数，一条消息一次，一键批量操作不多算；业务报错也占一次。
- 第21次不执行业务、不扣费；超限尝试不延长等待。普通聊天、无效指令及后台任务不计。
- 超限在原位置提示等待秒数，群聊提及用户；同账号每10秒至多提示一次，不因换群重复提示。
- 不是整分钟清零，旧记录满60秒才逐个释放额度。重启清空内存；不用于跨进程协调。
- 现有注册、群审核、部署名单和插件开关仍先行生效。此功能不代表黑名单管理已完成。

可持续性影响：没有新数据库/后台线程，过期账号会回收；提示自身限频。不能防住多账号协同刷指令或一次高成本操作，按需另行评估，不在本功能中扩大限制。
