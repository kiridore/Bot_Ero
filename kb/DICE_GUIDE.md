# 跑团骰子使用指南

玩家向说明书：DND 5E 与 COC 7th 的掷骰、检定、暗骰，以及配套的数值指令。
实现位置：`plugins/trpg_dice/`（骰子）、`plugins/trpg_vitals/`（HP/SAN）、`core/trpg/`（规则与角色卡计算）。

## 开始之前

跑团骰子只在群规则设定之后才完整可用。DM 先发 `/跑团 规则 dnd5e` 或 `/跑团 规则 coc7th`，之后群里所有骰子指令都会按这个规则解释；规则没设定时默认按 DND 5E 处理。

想用属性名和技能名直接掷骰（比如 `.r 力量`），需要先在网页端建好角色卡并设为当前角色，否则会提示先去建卡。

录制期间群里会自动进入静默模式，只有跑团相关的指令会响应；骰子结果会同时写进当次跑团记录，方便事后复盘。

## 最基础的掷骰：`.r`

`.r` 后面直接跟算式，支持加号、减号、倍数。

```
.r 1d20           掷一颗二十面骰
.r 2d6+3          掷两颗六面骰再加 3
.r 4d6            掷四颗六面骰（车卡时自己挑最高的三颗）
.r 1d100          掷百分骰
.r 3#d20          连掷三颗 d20，一次看完
```

只敲一个 `.r`、后面什么都不写，等于掷一颗百分骰（1d100）。连掷的写法是「数量#算式」，一次最多十组。

算式后面可以加一句说明，它会出现在回执里，方便 DM 分辨这一掷是干什么的：

```
.r 1d20 偷袭
→ 老张掷出了 D20=[16]=16 由于偷袭
```

## 用角色卡上的数值掷骰

在 DND 规则下，算式里可以直接写属性名或技能名，系统会按当前角色卡把它们换成对应的**加值**（不是属性原始数值）。

```
.r 力量           掷出你的力量加值
.r 1d20+力量      名副其实的力量检定
.r 1d20+隐秘      用你的隐秘加值
```

如果角色卡上还没有这个人，系统会回「你还没有角色卡，请到网页端创建」，不会静默失败。

## DND 的属性检定与豁免：`.rc`

`.rc` 专门用于 DND 的 d20 检定，会自动加上 d20 和各种调整。

```
.rc 力量                 d20 + 力量加值
.rc 隐秘                 d20 + 隐秘加值
.rc 力量 豁免            d20 + 力量豁免加值
.rc 优势 力量            d20 掷两次取高的，再加力量加值
.rc 劣势 隐秘            d20 掷两次取低的，再加隐秘加值
```

回执会写清楚它算了什么：

```
老张的力量检定: d20+3=[14]+3=17
老张的隐秘检定(优势): d20优势=[18 | 7]+5=23
```

如果算式里有比「单个属性」更复杂的东西（比如 `.rc 1d4+力量`），系统会先掷 d20 再单独掷括号里的部分，回执会把两段分开显示。

在 COC 规则下 `.rc` 会被拒绝，并提示改用 `.ra`。

## COC 的技能检定：`.ra`

`.ra` 是 COC 7 版的百分骰检定，有两种用法：写数字，或者写技能名。

```
.ra 70              按 70% 成功率检定
.ra 侦察            从当前 COC 角色卡读取「侦察」的成功率再检定
.ra 图书馆          别名会自动对上「图书馆使用」
```

回执会给出成功等级，并按七版规则判定大成功与大失败：

```
田宫的COC检定 D100=42  [技能=65] → 常规成功
田宫的COC检定 D100=8   [技能=65] → 极限成功
田宫的COC检定 D100=100 [技能=65] → 大失败
```

等级口径：掷出 01 记大成功；低于技能值五分之一是极限成功；低于二分之一是困难成功；不超过技能值是常规成功；技能值 ≥50 时只有掷出 100 才是大失败，技能值 <50 时掷出 96–100 都是大失败。

用技能名检定时如果成功，系统会自动在角色卡上给这项技能打「成长标记」，回执末尾出现「· 已标记技能成长」。标记是幕间成长的凭据；看不到它说明这一掷没有成功，或者用的是纯数字检定。

`.r c70` 是 `.ra 70` 的旧写法，两者等价。

## COC 的奖励骰与惩罚骰

七版里奖励骰和惩罚骰有两种写法，结果一样。

```
.r b2               奖励骰两颗
.r p1               惩罚骰一颗
.r 1d100b2          后缀写法，同样是奖励骰两颗
.r 1d100p1          后缀写法，惩罚骰一颗
```

最多十颗，超过会被拒绝。两种写法只在 COC 规则下可用，DND 下会提示切换规则。

## 暗骰：`.rh`

`.rh` 是给 DM 用的隐藏掷骰。它在群里只发一句「悄悄掷出骰子」，具体结果私聊发给发起者，其他人看不到。

```
.rh 1d20 察觉陷阱
.rh 1d100
.rh c60              COC 技能检定也支持暗骰
```

暗骰只能在群里使用，私聊里发会提示回到群里。录制期间暗骰结果会以「暗骰」身份写进跑团记录，但网页默认隐藏，需要打开「显示暗骰」开关才能看到。

## 与骰子配套的数值指令

下面三条不是掷骰，但团里几乎每次掷骰后都会用到。它们同样只在当前角色卡的规则与本团规则一致时生效。

```
.hp -5              扣 5 点当前 HP
.hp +3              回复 3 点
.hp -1d6            按掷骰结果扣血
.hp 满              当前 HP 回满
.san -1d6           COC 扣理智
.sc 1/1d6           理智检定：成功扣 1，失败扣 1d6
```

`.hp` 两套规则通用，`.san` 与 `.sc` 只在 COC 规则下可用。改自己的数值谁都可以，改别人的数值需要 DM 或超级用户用 `@` 指定目标。数值归零时会额外提示状态：DND 是「昏迷」，COC 是「濒死」，理智归零会提示「永久疯狂」。

## 常见拒绝与原因

「当前规则是 DND 5E，COC 检定请先由 DM 发送 /跑团 规则 coc7th」——在 DND 团里用了 COC 专用形式，或者 DM 还没设规则。

「当前规则是 COC 7th，属性检定请用 .ra 技能值」——在 COC 团里用了 `.rc`。

「角色卡里没有技能『驾驶』」——技能名对不上任何一项，可先用 `/跑团 角色 查看` 看卡上有哪些技能。

「本团规则是 COC 7th，目标角色卡是 DND 5E」——当前角色卡规则和本团规则不一致，去 `/跑团 角色 切换` 换一张，或让 DM 改规则。

「技能值应在1~199之间」——`.ra` 或 `.r c` 后面的数字超出范围。

## 已知限制

**不支持「取高/取低」写法**（`4d6k3`、`kh1`、`kl1` 这类）。写 `4d6k3` 目前只会掷 `4d6`，后面的 `k3` 被忽略，回执里也不会提示——车卡时请掷 `.r 4d6` 自己挑，或者连掷多组 `.r 3#4d6` 后手动取。

**未知字符会被当成结束标记**：表达式里出现不支持的东西（例如 `.r 2d6+abc` 里的 `abc`）时，解析到那里就停止，剩余部分不参与计算也不报错。想加说明请用**空格**隔开，例如 `.r 2d6 火球伤害`。

## 录制期间的变化

开录后群里只响应跑团相关的指令，骰子、数值、记录、角色卡这几类照常工作，其它插件全部静默。每颗骰子都会以机器人消息写进当天记录，回执里的文字就是记录里的文字——带上原因说明（`.r 1d20 偷袭`）能让复盘清楚得多。
