# 跑团骰子使用指南

玩家向说明书：DND 5E 与 COC 7th 的掷骰、检定、暗骰，以及配套的数值指令。
实现位置：`plugins/trpg_dice/`（骰子）、`plugins/trpg_vitals/`（HP/SAN）、`core/trpg/`（规则与角色卡计算）。

## 开始之前

跑团骰子只在群规则设定之后才完整可用。DM 先发 `/跑团 规则 dnd5e` 或 `/跑团 规则 coc7th`，之后群里所有骰子指令都会按这个规则解释；规则没设定时默认按 DND 5E 处理。

想用属性名和技能名直接掷骰（比如 `.r 力量`），需要先在网页端建好角色卡并设为当前角色，否则会提示先去建卡。

录制期间群里会自动进入静默模式，只有跑团相关的指令会响应；骰子结果会同时写进当次跑团记录，方便事后复盘。

## 最基础的掷骰：`.r`

`.r` 后面直接跟算式，支持加号、减号、倍数。

```
.r 1d20           掷一颗二十面骰
.r 2d6+3          掷两颗六面骰再加 3
.r 4d6k3          掷四颗六面骰取最高的三颗（DND 车卡标准做法）
.r 4d6kh3         同上，kh 是「keep highest」的完整写法
.r 4d6kl1         掷四颗取最低的一颗（少见，用于劣势骰一类判定）
.r 1d100          掷百分骰
.r 3#d20          连掷三颗 d20，一次看完
```

只敲一个 `.r`、后面什么都不写，等于掷一颗百分骰（1d100）。连掷的写法是「数量#算式」，一次最多十组。

算式后面可以加一句说明，它会出现在回执里，方便 DM 分辨这一掷是干什么的：

```
.r 1d20 偷袭
→ 老张掷出了 D20=[16]=16 由于偷袭
```

## 用角色卡上的数值掷骰

在 DND 规则下，算式里可以直接写属性名或技能名，系统会按当前角色卡把它们换成对应的**加值**（不是属性原始数值）。

```
.r 力量           掷出你的力量加值
.r 1d20+力量      名副其实的力量检定
.r 1d20+隐秘      用你的隐秘加值
```

如果角色卡上还没有这个人，系统会回「你还没有角色卡，请到网页端创建」，不会静默失败。

## DND 的属性检定与豁免：`.rc`

`.rc` 专门用于 DND 的 d20 检定，会自动加上 d20 和各种调整。

```
.rc 力量                 d20 + 力量加值
.rc 隐秘                 d20 + 隐秘加值
.rc 力量 豁免            d20 + 力量豁免加值
.rc 优势 力量            d20 掷两次取高的，再加力量加值
.rc 劣势 隐秘            d20 掷两次取低的，再加隐秘加值
```

回执会写清楚它算了什么：

```
老张的力量检定: d20+3=[14]+3=17
老张的隐秘检定(优势): d20优势=[18 | 7]+5=23
```

如果算式里有比「单个属性」更复杂的东西（比如 `.rc 1d4+力量`），系统会先掷 d20 再单独掷括号里的部分，回执会把两段分开显示。

在 COC 规则下 `.rc` 会被拒绝，并提示改用 `.ra`。

## COC 的技能检定：`.ra`

`.ra` 是 COC 7 版的百分骰检定，有三种用法：写数字、写技能名、写属性名。

```
.ra 70              按 70% 成功率检定
.ra 侦察            从当前 COC 角色卡读取「侦察」的成功率再检定
.ra 图书馆          别名会自动对上「图书馆使用」
.ra 力量            属性检定：从角色卡读取力量数值（例：力量 60 → 按 60 检定）
.ra STR             英文缩写也可以，大小写不敏感（STR / CON / SIZ / DEX / APP / INT / POW / EDU）
.ra 幸运            幸运、信用评级同样是卡上的数值
```

属性检定的回执用 `[力量=60]` 标记，技能检定用 `[技能=65]`，一眼能分清读的是哪个数。**属性不会打成长标记**（规则里只有技能有成长标记）。

回执会给出成功等级，并按七版规则判定大成功与大失败：

```
田宫的COC检定 D100=42  [技能=65] → 常规成功
田宫的COC检定 D100=8   [技能=65] → 极限成功
田宫的COC检定 D100=100 [技能=65] → 大失败
```

等级口径：掷出 01 记大成功；低于技能值五分之一是极限成功；低于二分之一是困难成功；不超过技能值是常规成功；技能值 ≥50 时只有掷出 100 才是大失败，技能值 <50 时掷出 96–100 都是大失败。

用技能名检定时如果成功，系统会自动在角色卡上给这项技能打「成长标记」，回执末尾出现「· 已标记技能成长」。标记是幕间成长的凭据；看不到它说明这一掷没有成功，或者用的是纯数字/属性检定。**信用评级永远不打勾**（规则 5.11），`.ra 信用评级` 仍可检定，只是不会留下成长标记。**克苏鲁神话不再是技能行**——它的数值在建卡页「背景」里的「克苏鲁神话」一格，`.ra 克苏鲁神话` 直接读这个数，同样不打勾。

`.r c70` 是 `.ra 70` 的旧写法，两者等价。

COC 团里不要用 `.r 力量`——`.r` 是自由算式，`力量` 那类名字会被当成人家的 DND 加值处理，数不对；系统现在会直接拦下并提示改用 `.ra 力量`。

## COC 的奖励骰与惩罚骰

七版里奖励骰和惩罚骰有两种写法，结果一样。

```
.r b2               奖励骰两颗
.r p1               惩罚骰一颗
.r 1d100b2          后缀写法，同样是奖励骰两颗
.r 1d100p1          后缀写法，惩罚骰一颗
```

最多十颗，超过会被拒绝。两种写法只在 COC 规则下可用，DND 下会提示切换规则。

## 暗骰：`.rh`

`.rh` 是给 DM 用的隐藏掷骰。它在群里只发一句「悄悄掷出骰子」，具体结果私聊发给发起者，其他人看不到。

```
.rh 1d20 察觉陷阱
.rh 1d100
.rh c60              COC 技能检定也支持暗骰
```

暗骰只能在群里使用，私聊里发会提示回到群里。录制期间暗骰结果会以「暗骰」身份写进跑团记录，但网页默认隐藏，需要打开「显示暗骰」开关才能看到。

## 与骰子配套的数值指令

下面三条不是掷骰，但团里几乎每次掷骰后都会用到。它们同样只在当前角色卡的规则与本团规则一致时生效。

```
.幸运 -10              COC 花掉 10 点幸运
.幸运 +1d6             KP 奖励，按骰子给
.hp -5              扣 5 点当前 HP
.hp +3              回复 3 点
.hp -1d6            按掷骰结果扣血
.hp 满              当前 HP 回满
.san -1d6           COC 扣理智
.sc 1/1d6           理智检定：成功扣 1，失败扣 1d6
```

数值参数支持「一个骰子项 + 一个数字修饰」：`.hp -2d6+3`、`.san +1d4-1`、`.sc 1/1d4+1`。合计最小为 0（`1d4-2` 掷出 1 时按 0 计，不会因为负值反过来加血），带修饰时回执会把构成写出来：

```
.sc 1/1d4+1   → SAN 50 → 46（d4+1=4（3+1））
.san +1d4-3   → SAN 50 → 50（+d4-3=-2→0（1-3））
```

注意 `.san -1d4+1` 的负号作用于**整体**（等于 −(d4+1)），想「扣 d4 但加 1」请分两步发。

`.hp` 两套规则通用，`.san`、`.sc`、`.ti` 与 `.幸运` 只在 COC 规则下可用。`.幸运` 截断在 0–99：花超了只到 0 并提示「幸运已见底」，加超了只到 99；同样支持 `@` 指定目标（需 DM 或超级用户），也支持骰子表达式。改自己的数值谁都可以，改别人的数值需要 DM 或超级用户用 `@` 指定目标。数值归零时会额外提示状态：DND 是「昏迷」，COC 是「濒死」，理智归零会提示「永久疯狂」。

## 疯狂发作：`.ti`

```
.ti                 掷一次表Ⅶ「疯狂发作-即时症状」（1D10）
.ti @某人           DM / 超级用户替他人掷
```

回执会给出症状、持续轮数与临时性疯狂的小时数：

```
哈维 陷入疯狂发作（表Ⅶ 即时症状）
· D10=4 → 偏执
  有人在暗中窥视、同伴中有人背叛、没有人可以信任、万事皆虚
· 症状持续 1D10 轮 → 7 轮
· 临时性疯狂持续 1D10 小时 → 5 小时（整段是否适用由守秘人裁定）
```

- 抽到 **9 恐惧 / 10 躁狂** 时会再骰 D100 从表Ⅸ/表Ⅹ 抽具体症状，并写进角色卡的「背景 · 恐惧症和狂躁症」
- 抽到 **5 人际依赖** 时，卡上「重要之人」有内容就一并带出
- 这是**手动触发**的：规则里的「损失 ≥5 理智 → 智力检定通过 → 临时性疯狂」由守秘人裁定，指令不自动判定
- 不改 SAN，也不记录「疯狂中」状态（那属于后续玩法）

## 常见拒绝与原因

「当前规则是 DND 5E，COC 检定请先由 DM 发送 /跑团 规则 coc7th」——在 DND 团里用了 COC 专用形式，或者 DM 还没设规则。

「当前规则是 COC 7th，属性检定请用 .ra 技能值」——在 COC 团里用了 `.rc`。

「角色卡里没有技能『驾驶』」——技能名对不上任何一项，可先用 `/跑团 角色 查看` 看卡上有哪些技能。

「本团规则是 COC 7th，目标角色卡是 DND 5E」——当前角色卡规则和本团规则不一致，去 `/跑团 角色 切换` 换一张，或让 DM 改规则。

「技能值应在1~199之间」——`.ra` 或 `.r c` 后面的数字超出范围。

## 表达式规则与报错

算式里允许的符号是：数字、`d`、`k`/`kh`/`kl`、`+ - * / ( )`、`#`（连掷）、`%`（百分骰）、`b`/`p`（COC 奖惩骰，仅 COC 规则）。

出现别的字符会**直接报错**并指出是哪一段解析不了，例如 `.r 2d6+abc` 会回「无法解析「abc」……说明文字请用空格与算式分开」。想加说明请用空格隔开：`.r 2d6 火球伤害`。

`k` 系列只能跟在骰子后面：`4d6k3` 保留最大的 3 颗，`4d6kl1` 保留最小的 1 颗，`4d6k` 等于保留 1 颗。保留颗数超过骰子数量会报错。

## 录制期间的变化

开录后群里只响应跑团相关的指令，骰子、数值、记录、角色卡这几类照常工作，其它插件全部静默。每颗骰子都会以机器人消息写进当天记录，回执里的文字就是记录里的文字——带上原因说明（`.r 1d20 偷袭`）能让复盘清楚得多。
