# coc-character-sheet — 变更（年龄调整：未保存时的说明）

## ADDED Requirements

### Requirement: 未保存的卡要说明年龄调整需要先保存
建卡页在还没有卡号（`CHAR_ID` 为空）时，年龄调整面板 MUST 显示「先保存角色卡，再回到这里应用年龄调整」的说明，并把「应用年龄调整」与「不再提示」MUST 置为禁用。

#### Scenario: 新建卡
- **WHEN** 打开 `/trpg/coc` 新建一张卡，年龄 45、属性已填
- **THEN** 面板顶部出现「先保存角色卡…」的提示，「应用年龄调整」「不再提示」均为灰态

#### Scenario: 已保存的卡
- **WHEN** 打开 `/trpg/coc/<编号>` 编辑一张已保存的卡
- **THEN** 面板不出现该提示，按钮按体能合计与属性是否已填正常启用/禁用
