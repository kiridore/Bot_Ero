# coc-character-sheet — 变更（资产栏）

## ADDED Requirements

### Requirement: 资产字段与生活水平档位
COC 角色卡资产 SHALL 记录：币种、生活水平、消费水平、现金、其他资产描述，以及「其他资产表」五类（交通工具 / 住所 / 奢侈品 / 股票·证券 / 其他）与剩余资产值。生活水平 MUST 为六档之一（身无分文 / 拮据 / 标准 / 小康 / 富裕 / 富豪）；币种 MUST 为参考表内的币种之一或空。生活水平 SHOULD 默认由信用评级推导（0 / 1–9 / 10–49 / 50–89 / 90–98 / 99），但 MUST 允许手动改选。

#### Scenario: 信用评级分档
- **WHEN** 玩家把信用评级改为 30
- **THEN** 生活水平自动落到「标准」，并提示信用评级 30 通常对应「标准」

#### Scenario: 手改档位
- **WHEN** 玩家把生活水平改成「富裕」
- **THEN** 保存成功，页面提示与信用评级推导值不一致

#### Scenario: 非法生活水平
- **WHEN** 资产里提交「贫穷」
- **THEN** 返回 400 并提示不在 6 档之内

### Requirement: 资产参考值
系统 SHALL 按币种与信用评级提供现金 / 其他资产 / 消费水平的参考值（固定值或「CR×倍数」），供建卡页「按规则填入」。参考值 MUST NOT 覆盖玩家已手填的金额，除非玩家主动点击填入。

#### Scenario: 按规则填入
- **WHEN** 币种为日元、信用评级 30，点击「按规则填入」
- **THEN** 现金填 120000、消费水平填 25000、生活水平填「标准」

#### Scenario: 未知币种
- **WHEN** 请求 `asset-reference?currency=XXX`
- **THEN** 返回 400

### Requirement: 资产总和
资产总和 SHALL 由当前现金与其他资产表五类相加得出并只读展示；现金或分类值含非数字内容时 MUST 视为 0 而不得报错。

#### Scenario: 合计
- **WHEN** 现金 120000、交通工具 300000，其余为空
- **THEN** 资产总和显示 420000
