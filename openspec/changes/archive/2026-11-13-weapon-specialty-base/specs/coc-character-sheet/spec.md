# coc-character-sheet — 变更（格斗/射击专攻基础值）

## ADDED Requirements

### Requirement: 格斗与射击专攻按附表取基础成功率
格斗与射击的子技能 SHALL 各自拥有独立的基础成功率，取值以 `COC7空白卡CY26.3` 附表（C11:E13 / 人物卡 E38）为准：格斗——斗殴 25、鞭子 5、电锯 10、斧 15、剑 20、绞具 15、链枷 10、矛 20；射击——手枪 20、步枪/霰弹枪 25、冲锋枪 15、弓 15、喷射器 10、机枪 10、重武器 10。`类别:专攻` 写法（`射击:手枪`、`格斗:剑`）MUST 取到与裸名相同的值；常见别名（弓术→弓、步枪 / 霰弹枪→步枪/霰弹枪、链锯→电锯）SHALL 一并识别。未识别的专攻 MUST 按 0 处理且不报错。

#### Scenario: 新卡写法
- **WHEN** 角色卡上写 `射击:步枪/霰弹枪`
- **THEN** 该技能基础成功率是 25，不是 0

#### Scenario: 别名
- **WHEN** 卡上写 `射击:弓术` 或裸写 `弓术`
- **THEN** 基础成功率是 15

#### Scenario: 未知专攻
- **WHEN** 卡上写 `射击:飞天`
- **THEN** 基础成功率为 0，保存不报错

### Requirement: 基础值表唯一来源
`skill_base_map()` SHALL 同时包含裸专攻名与 `格斗:xxx`、`射击:xxx` 形式；网页播种新技能行、`finalize()` 兜底、`.ra` 取值 MUST 全部使用该表，避免同一技能在不同路径得到不同数字。

#### Scenario: 播种技能行
- **WHEN** 玩家在建卡页添加「射击:手枪」
- **THEN** 基础值列自动填 20
