# coc-character-sheet — 变更（基础值单一来源）

## ADDED Requirements

### Requirement: 技能基础值单一来源
系统 SHALL 由一份「技能基础值表」统一提供标准技能、附表专攻与武器技能的基础成功率。读时兜底（`finalize`）、成长补行（`growth.mark`）、网页播种与任意查值 MUST 使用同一份数据；同一技能在不同路径得出的基础值 MUST 相同。建卡播种的范围 MUST 仅限 39 项标准技能（含闪避按敏捷派生），专攻与武器技能 MUST NOT 被自动铺进每张卡。卡片上已保存的基础值 SHOULD 优先于表值。

#### Scenario: 专攻技能
- **WHEN** 卡上没有「科学:化学」，玩家通过准备工作补出该行
- **THEN** 基础值为 1%（与 `finalize` 读时兜底一致），而不是 0

#### Scenario: 武器技能
- **WHEN** 武器表从武器库选中「黄铜指虎」（使用技能 斗殴）
- **THEN** 成功率按 25 填入，而不是 0

#### Scenario: 播种范围
- **WHEN** 新建角色卡
- **THEN** 技能表只出现 39 项标准技能与闪避，不出现「技艺:表演」「斗殴」

#### Scenario: 手改值优先
- **WHEN** 玩家把「会计」的基础值改成 12 并保存
- **THEN** 之后各处仍按 12 显示，不被表值 5 覆盖
