# plugin-event-processing（增量）

## MODIFIED Requirements

### Requirement: 合并文本与必需输出模块

系统 SHALL 通过不可关闭的输出模块发送全部插件的聊天消息，MUST NOT 保留绕过该模块的插件发送路径；撤回、资源下载与其他非聊天消息接口不属于发送，可以继续直接调用。仅同一操作、同一接收位置、相同非空合并标记的普通文本可合并，按显示顺序及提交先后稳定排列，以换行分隔。无标记请求和特殊消息保持独立。

#### Scenario: 同标记但不同目的地

- **WHEN** 一个操作向群和私聊提交相同标记的文本
- **THEN** 分别发送，私聊内容不得进入群消息

#### Scenario: 多段文字与图片

- **WHEN** 同一目的地收到可合并文本、未标记文本和图片请求
- **THEN** 只合并符合条件的普通文本，其他请求不丢失、不被当作纯文字拼接

#### Scenario: 非当前会话的目标

- **WHEN** 插件需要向当前会话之外的位置发送（逐玩家私聊、活动所属群、默认群推送、定时通知）
- **THEN** 提交时必须显式给出群号或私聊账号，不得依赖事件位置推断

#### Scenario: 时机与失败语义

- **WHEN** 插件提交消息后发送失败
- **THEN** 已提交的业务数据保留，消息不自动重试，且同一事件内提交的全部消息在该事件处理结束时统一发送

#### Scenario: 旧发送入口退役

- **WHEN** 某个插件完成迁移
- **THEN** 其聊天消息只经统一输出提交，迁移清单同步标记为已迁移；后续新增插件同样不得直接调用发送接口
