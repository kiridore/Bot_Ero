# trpg-record-web — 变更（回到顶部按钮显隐）

## ADDED Requirements

### Requirement: 回到顶部按钮按滚动位置显隐
记录详情页的「回到顶部」悬浮按钮 SHALL 只在页面向下滚动超过 300 像素时显示；未达阈值时 MUST 隐藏且不可聚焦（`tabIndex=-1`）。隐藏时 MUST 保留占位，不使其它悬浮按钮位移。另外两个悬浮按钮 MUST 常驻。

#### Scenario: 页面在顶部
- **WHEN** 打开记录页、尚未滚动
- **THEN** 只显示「隐藏暗骰」「隐藏场外发言」两个按钮，「回到顶部」不可见也不可聚焦

#### Scenario: 向下滚动
- **WHEN** 向下滚动超过 300 像素
- **THEN** 「回到顶部」按钮出现并可点击

#### Scenario: 回到顶部之后
- **WHEN** 点击「回到顶部」滚回页首
- **THEN** 该按钮重新隐藏
