# DND 5E 车卡升级为建卡工具

## Why

所有者按「网页版建卡工具而不是角色卡录入器」的标准检查 COC 之外的 DND 卡片，发现 DND 编辑器只有生成按钮没有约束：购点超支不拦、属性范围与服务端校验缺失、种族加值可能被玩家手填后重复计算、技能数不按职业限制、HP 只能看建议文字。所有者裁定按建卡工具标准全面对齐。

## What Changes

- **属性生成方式入库**：卡片新增 `attributes_mode`（`point_buy` / `rolled` / `array` / `manual`），服务端据此校验基础值。
- **服务端校验**：购点 8–15 且总花费 ≤27；掷骰 3–18；标准数组取值必须是 15/14/13/12/10/8；手填 1–30；种族/职业必须在规则表内；技能必须在职业可选范围内且数量不超职业上限（吟游诗人任意项）；豁免熟练最多 2 项。不通过返回 400 与中文原因。
- **种族加值语义**：输入框 = 基础值，界面显示「基础 X + 种族 Y = 最终 Z」，派生值只加一次。
- **HP 一键计算**：按「1 级取满骰 + 之后每级骰面均值向上取整 + 体质加值 × 等级」计算并填入。
- **职业可选技能清单**：`core/trpg/rules.py` 的 CLASSES 增加 `skills` 清单（吟游诗人为 `any`）。
- 背景与起始装备**不做**联动（所有者选择只提示不自填）。

## Capabilities

### New Capabilities

- `dnd-character-builder`：DND 5E 建卡约束（属性生成方式与取值范围、购点预算、种族加值语义、职业技能数、HP 计算）。

### Modified Capabilities

- 无（DND 车卡此前没有对应能力规范）。

## Scope and Compatibility

- 旧卡没有 `attributes_mode` 时按 `manual` 处理（1–30），不会因新校验突然无法保存；旧卡若把种族加值写进了基础值，编辑时会显示「基础 = 最终」，由玩家自行决定是否改回。
- 背景与装备仍为自由文本。
- 无数据库变更、无新增依赖。
