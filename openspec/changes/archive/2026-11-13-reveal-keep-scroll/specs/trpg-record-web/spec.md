# trpg-record-web — 变更（暗骰开关的滚动位置）

## ADDED Requirements

### Requirement: 切换暗骰时保持阅读位置
记录详情页在切换「显示暗骰 / 隐藏暗骰」导致重载时，SHALL 保持用户当前阅读位置：若用户不在页面底部，重载后 MUST 把原先视口里的第一条消息放回原来的位置（`scrollTo` 使用 `behavior: "auto"`，不产生滚动动画）；若用户已在底部，则 SHALL 继续跟随到底部。

#### Scenario: 翻到中间时切换
- **WHEN** 用户在记录中部（不在底部）点击「显示暗骰」
- **THEN** 暗骰消息出现，视口仍停在原来那条消息上，不会跳到最底部

#### Scenario: 在底部时切换
- **WHEN** 用户已经滚到最底部再切换暗骰
- **THEN** 切换后仍停在底部，能看到新出现/隐藏的消息

#### Scenario: 首次打开
- **WHEN** 打开记录页
- **THEN** 仍按既有行为滚动到底部
