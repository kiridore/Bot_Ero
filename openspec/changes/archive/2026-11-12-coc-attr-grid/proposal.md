# 属性区改 3×3 并加「您的角色可能」九宫格

## Why

源码人物卡（`docs/COC7空白卡CY26.3.xlsx`）的属性区本身就是 3×3：力量/敏捷/意志、体质/外貌/教育、体型/智力/幸运。我们目前是自适应网格，宽屏下九项挤在一行、窄屏下变成两行，和原卡不对应；每个属性的重掷按钮还是「掷」文字，九个按钮挤在输入框旁边很吵。

原卡在属性右侧还有一列由公式驱动的趣味描述（表头「您的角色可能（只是可能！）」，单元格 AJ3/AJ5/AJ7/AV3/AV5/AV7/BD3/BD5/BD7），按属性值分档给出「虚弱，孱弱」「超乎常人的力量」「被幸运女神所眷顾」这类文案——建卡时比干巴巴的数字直观得多，我们现在完全没有。

## What Changes

- 属性区改为左 3×3 输入格 + 右 3×3 描述格，两侧同序对齐（力量/敏捷/意志、体质/外貌/教育、体型/智力/幸运）。
- 每个属性的重掷按钮由「掷」改为 `🎲` 图标（带 `title`/`aria-label`），顶部「全部重掷」改为「🎲 全部重掷」；幸运并入 `ATTRS` 统一处理，不再单独掷一次。
- 右格文案抄录原卡 IF 链（9 个属性各一组分档），值变化时实时刷新；值为 0 时不显示。

## Capabilities

### Modified Capabilities

- `coc-character-sheet`：属性区的排列与描述展示。

## Scope and Compatibility

- 只改建卡页布局与展示，不改任何计算与校验。
- 分档文案照抄原卡，含原卡的俏皮措辞（「过分了喂！」「你怕是个假人吧」）。
- 原卡属性值可超过 99（体型、意志），分档上限按原卡设置（体型到 999、意志到 999）。
- 无数据库变更、无新增依赖。
