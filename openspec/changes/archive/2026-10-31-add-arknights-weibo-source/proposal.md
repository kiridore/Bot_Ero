# 新增明日方舟官方微博消息源

## Why

所有者要求将 https://m.weibo.cn/u/6279793937 加为消息源，并确认摘要、首图或封面、原文链接的展示方案。用户提供成功 JSON 样本，账号为明日方舟Arknights。本次在 master 实现，不修改 dev。

## What Changes

- 保留 1 号 FF14 国服官网，追加 2 号「明日方舟官方微博」，稳定 key `weibo_6279793937`。
- 解析公开 getIndex 接口：card_type=9 的本账号微博，数字 id 去重、HTML 转纯文本、带时区发布时间、首图或视频/文章封面。原文链接只用固定微博域名和数字 id 构造。
- 摘要最多 1000 字，超长加省略号；不额外获取全文、不下载视频、不发送多图。标题使用「明日方舟Arknights 发布微博」。
- 按请求页码从 1 翻页，非置顶内容均早于 48h 或空 cards 时停止；旧置顶不导致提前停止。最多 20 页，超限或异常整源失败、不返回部分结果。每请求超时 25 秒。
- 复用现有半小时轮询、默认群发送、AT 订阅者、首次基线和失败保留游标；不改数据库。
- 新功能版本 1.60.0，同步新闻目录、指令说明与知识库。

## Capabilities

### New Capabilities
- 无。

### Modified Capabilities
- `news-subscription`：扩充注册表并新增微博解析要求。

## Non-goals

不登录微博、不持有 Cookie、不绕过验证码、不改订阅权限或默认群策略、不增加其他账号、不修改旧微博时重复推送。

本机匿名请求微博接口返回 HTTP 432。用户提供成功响应，足以验证解析结构，但不代表机器人部署环境已可匿名访问。本次交付要求离线解析和失败保护测试通过；真实运行环境访问与QQ群发送另行验证，不声称已完成联调。
