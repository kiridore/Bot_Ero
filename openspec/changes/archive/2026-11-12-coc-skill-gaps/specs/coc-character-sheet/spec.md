# coc-character-sheet — 变更（成长标记、武器技能、资产合计）

## ADDED Requirements

### Requirement: 技能默认值的成长标记
成功使用某项技能后，系统 SHALL 能为其打上成长标记，即使该技能行尚未写入卡片；此时 SHALL 按规则补出该行（基础值优先取人物卡附表，其次武器技能表，均无则留空由默认值兜底）。未知技能 MUST 返回失败且不修改卡片。已存在（含别名写法）的技能行 MUST 复用，不得重复添加。

#### Scenario: 卡上没有会计
- **WHEN** 玩家用默认值成功的 `.ra 会计`
- **THEN** 卡片补出「会计（基础 5）」并打上成长标记

#### Scenario: 别名命中已有行
- **WHEN** 卡上有「侦察」行，玩家用「侦查」触发成功
- **THEN** 复用「侦察」行打勾，不新增「侦查」行

#### Scenario: 未知技能
- **WHEN** 技能名在附表与技能表里都不存在
- **THEN** 不打勾、不修改卡片

### Requirement: 武器技能可用
武器技能（斗殴、手枪、步枪/霰弹枪、弓、剑、斧、矛、鞭子、电锯、链枷、绞具、冲锋枪、机枪、重武器、喷射器、爆破、炮术、投掷、电气维修）SHALL 拥有规则基础值，`.ra <武器技能>` 可直接检定；附表写作「弓术」时 MUST 等价于「弓」。武器技能 MUST NOT 被自动加入每张卡的技能表。

#### Scenario: 检定斗殴
- **WHEN** 卡上没有「斗殴」行，玩家发送 `.ra 斗殴`
- **THEN** 按 25% 检定，而不是报「角色卡里没有技能」

#### Scenario: 成长标记
- **WHEN** `.ra 手枪` 成功
- **THEN** 卡片补出「手枪（基础 20）」并打勾

### Requirement: 资产合计单一来源
建卡页与角色卡查看页 SHALL 使用同一份资产合计实现（`core/web/static/trpg_assets.js`），口径为「当前现金 + 其他资产表五类」。含中文单位的文本金额（如「5先令」）MUST 按 0 计；带货币符号或千分位的数字 SHOULD 正确解析。

#### Scenario: 两页一致
- **WHEN** 现金 120000、交通工具 300000
- **THEN** 建卡页与查看页都显示资产总和 420000

#### Scenario: 文本金额
- **WHEN** 现金写作「5先令」
- **THEN** 合计按 0 计
